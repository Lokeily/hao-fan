如何配置 API Key

三步即可让你的扩展连上所选服务商。密钥只会被发给对应服务商，不会经过任何中转。

1

打开设置

点击工具栏「好翻」图标 → 打开「设置」。

2

选择服务商并填 Key

从下拉列表选择服务商（如 DeepSeek、OpenAI），填入你在该平台申请的 API Key，设置目标语言。

3

测试连接

点击「测试连接」确认可用，回到网页点「译」按钮即可开始翻译。

想先体验？在设置中选择「Google 翻译」即可免 Key 使用。所有 Key 仅存于浏览器本地 storage.local，按服务商隔离。

还不会安装？看安装指南 →

你的 Key，只住在你本地

API Key 保存在浏览器本地的 storage.local，按服务商隔离存储。它只会随你发起的翻译请求，发往对应的服务商——绝不会经过好翻的任何服务器，我们既看不到，也收不到。

想彻底清除？卸载扩展或清除站点数据即可，没有账号、没有残留。
