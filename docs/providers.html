选型建议

🧭 怎么选服务商

不同场景适合不同的引擎。下面四张卡帮你快速对号入座——选错了也随时能在设置里换。

想先免费用

在设置里选「Google 翻译（免 Key）」，不用申请任何账号就能翻译。缺点是端点不稳定，只适合体验。

追求译文质量

长文、专业内容优先 DeepSeek、OpenAI、Google Gemini 这类大模型，配合上下文感知与术语表，连贯度更高。

数据最敏感

用 Ollama 等本地模型，翻译请求不出本机；或在设置里配置你自建、可信的兼容接口，密钥与流量都只在你掌控之内。

国内网络环境

智谱 GLM、腾讯混元、通义千问、Kimi、百川、豆包等国内大模型，接入稳定、延迟低，中文语感也更贴近本地习惯。

进阶玩法：开启「备用引擎故障转移」与「长文强模型」，好翻会在主引擎报错时自动切备用一次，单段超长时改用更强的模型——具体见功能特性。

配置指南

🔑 如何配置 API Key

三步即可让你的扩展连上所选服务商。密钥只会被发给对应服务商，不会经过任何中转。

1

打开设置

点击工具栏「好翻」图标 → 打开「设置」。

2

选择服务商并填 Key

从下拉列表选择服务商（如 DeepSeek、OpenAI），填入你在该平台申请的 API Key，设置目标语言。

3

测试连接

点击「测试连接」确认可用，回到网页点「译」按钮即可开始翻译。

想先体验？在设置中选择「Google 翻译」即可免 Key 使用。所有 Key 仅存于浏览器本地 storage.local，按服务商隔离。

还不会安装？看安装指南 →

你的 Key，只住在你本地

API Key 保存在浏览器本地的 storage.local，按服务商隔离存储。它只会随你发起的翻译请求，发往对应的服务商——绝不会经过好翻的任何服务器，我们既看不到，也收不到。

想彻底清除？卸载扩展或清除站点数据即可，没有账号、没有残留。
