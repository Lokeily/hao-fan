怎么选服务商

没有「最好」，只有「最合适」。

想零配置先体验

选「Google 翻译（免 Key）」，无需任何 Key 就能看到翻译效果，适合第一次试用。

中文互译为主

DeepSeek、智谱 GLM、腾讯混元等国内模型对中文与术语更友好，性价比也高。

看重隐私与离线

用 Ollama 等本地模型，数据不出本机；代价是需要自备算力与本地服务。

已有 OpenAI 生态

直接填你的 Base URL 与模型即可，OpenAI、OpenRouter 或自建兼容服务都能接。

怎么配置

三步，把翻译能力接进来。

1

选服务商

在扩展设置里从列表选择你要用的服务商（或「自定义」填入你的 OpenAI 兼容端点）。

2

填 Key 与模型

按服务商文档填写 API Key、Base URL（若需）与模型名称。密钥仅保存在你本地浏览器。

3

设目标语言

选择目标语言与翻译风格，回到网页点工具栏「译」按钮即可开始翻译。
