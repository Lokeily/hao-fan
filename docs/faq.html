常见问题

关于好翻是什么、怎么用、数据安全，这里先回答最容易遇到的几个问题。

好翻收费吗？

不收费。好翻基于 MIT 许可证开源，可免费使用。你需要自行承担所选用翻译服务商的 API 费用（选择 Google 翻译免 Key 模式则连这笔也免）。

我的 API Key 安全吗？

你的 API Key 仅保存在浏览器本地（storage.local），并且不同服务商的密钥分别存储，仅随对应服务的请求发送。翻译请求直连你选择的服务商，不经过任何由好翻控制的服务器。

支持哪些浏览器？

好翻基于 Manifest V3，可在 Chrome、Edge 等 Chromium 系浏览器以开发者模式加载；Firefox 可通过「临时载入附加组件」方式使用。应用商店上架后也可从商店一键安装。

需要联网吗？能离线用吗？

翻译本身需要联网，因为待译文本会发往你配置的翻译服务。已翻译的内容会缓存在本地，因此在缓存有效期内、且页面语言已是目标语言时，可以更快显示而不重复请求。

支持哪些语言？

支持的语言取决于你选择的翻译服务商。你可以在设置里指定源语言和目标语言；当页面语言已是目标语言时，好翻会自动跳过翻译。

好翻会收集我的数据吗？

不会。好翻不运营服务器、不收集遥测、不投放广告、不追踪浏览行为。它只在本地保存你的配置、API Key、使用统计、按网站暂停列表与译文缓存，且译文缓存仅用于避免重复请求。

划词翻译怎么用？

在网页上选中一段文字，好翻会以独立浮窗展示译文，不改变原网页结构。也可通过右键菜单的「翻译选中文字」触发。

图片翻译需要什么？

图片翻译会对网页图片或本地图片先做 OCR 识别，再翻译识别出的文字，需要配置支持视觉能力的模型。普通文本翻译不需要视觉模型。

术语表怎么用？

在设置里添加「原文 → 固定译法」的条目。翻译时若命中术语，会直接采用你设定的译法，既保证一致性，也省下请求额度。

动态加载的内容（弹窗、无限滚动）能翻译吗？

可以。好翻会监测页面变化，对异步加载、模态框、下拉与无限滚动等新增内容自动补译，单页应用切换也不漏。

这是远程代码吗？有安全风险吗？

不是远程代码。好翻所有逻辑都打包在扩展内，运行时不从外部下载并执行任何 JavaScript，并配合严格的 CSP（script-src 'self'）。待译文本也会被标记为「数据而非指令」以降低注入风险。

如何卸载？

在浏览器的扩展管理页面移除好翻即可，其本地数据会随之一并清除。你也可以先在扩展设置里清除配置与缓存。

怎么确认 API Key 填对了？

在扩展设置里填好服务商与 Key 后，点击「测试连接」：返回成功即说明配置可用；若报错，请核对 Key、Base URL 与模型名称是否与服务商文档一致。

翻译到一半能取消吗？

可以。翻译进行中，再次点击网页右下角的蓝色「译」按钮即可取消当前翻译任务。
