问：好翻会收集我的数据吗？

下面按主题整理了大家最常问的问题，点开即可看真实回答；也可以用上面的标签快速筛选。

好翻收费吗？

不收费。好翻是开源、免费的浏览器扩展，没有使用额度限制，也不会向你收费。所有翻译费用仅来自你自行配置的服务商（如 DeepSeek、OpenAI 等），由对应服务商按它们的计费规则向你收取。

好翻会收集我的数据吗？

不会。项目没有遥测、广告追踪或用户行为统计；没有服务器端日志，翻译请求不经过任何中转服务器；扩展不注册账号，也不要求登录。完整说明见隐私政策。

我需要 API Key 吗？

如果你选的是 AI 类服务（DeepSeek、OpenAI、智谱等），需要填入你在该平台申请的 API Key。但如果你想先体验，在设置里选择「Google 翻译（免 Key）」即可免 Key 使用——只不过它走的是非官方免费端点，稳定性不保证，建议仅用于体验。

支持哪些浏览器？

支持 Chrome、Edge（基于 MV3）与 Firefox（以 MV2 临时载入方式运行）。当前以开发者模式手动加载为主，商店上架完成后即可一键安装。

支持哪些翻译服务？

内置 12 家 AI 服务商（DeepSeek、OpenAI、Google Gemini、OpenRouter、智谱 GLM、腾讯混元、通义千问、Kimi、百川智能、豆包、Ollama 本地模型等）与 3 家传统机器翻译（Google 翻译免 Key、DeepL、Microsoft 翻译），也支持任意 OpenAI 兼容接口。详见翻译服务页。

为什么 Firefox 安装后重启浏览器，扩展就不见了？

这是因为 Firefox 对未签名扩展的限制：临时载入的附加组件在浏览器重启后会被清除。这是浏览器行为，不是扩展的 Bug。等 Firefox AMO 上架并签名后即可正常常驻。在此期间，每次重启后重新「临时载入」一次即可。

我的 API Key 安全吗？

安全。各服务商的 API Key 仅保存在你浏览器的本地 storage.local，按服务商隔离存储；Key 只随你选择的翻译请求发送给对应服务商，扩展不会把它发给任何其他方；卸载扩展即清除。

翻译请求会经过你们的服务器吗？

不会。翻译请求由扩展直连你设置中所选服务商的 API 端点，本项目不参与、不中转、不存储。扩展页面还启用了严格的内容安全策略，禁止加载远程脚本。

怎么在网页上触发翻译？

有三种方式：① 点击右下角蓝色「译」按钮；② 选中文字后使用划词翻译浮窗；③ 右键菜单选择「翻译本页 / 翻译选中内容」。也可以用快捷键 Alt+T 直接翻译当前网页（快捷键可在浏览器设置页自定义）。

和普通机器翻译相比，好翻的翻译有什么不同？

好翻把译文以「沉浸式双语对照」的方式嵌在原文下方，并可流式输出、结合上下文、对数字/URL/代码做保真校验、自动沉淀术语。它底层调用的仍是你选择的 AI 或传统翻译服务，差异化主要在阅读体验与工程优化上。

支持哪些语言？

取决于你选择的服务商。AI 类服务基本支持其官方覆盖的所有语种；目标语言在设置中选择，默认常译为中文。好翻本身不限定语种，只负责把网页原文送给你选的模型、再把译文呈现出来。需要翻译某个小语种时，换个支持该语种的服务商即可。

翻译很慢，或提示超时怎么办？

先确认：API Key 是否有效、网络是否正常、所选模型是否可用。长文会分块发送，首段采用流式输出以缩短等待；可在设置中调整超时与重试次数，并开启「备用引擎故障转移」（限流或报错时自动切换到备用引擎）。如果长期偏慢，多半是所选模型本身响应慢，换一个更快的模型通常立竿见影。

能在手机上使用吗？

目前好翻是桌面浏览器扩展，支持 Chrome / Edge / Firefox 的桌面版，暂不支持手机端浏览器（Safari iOS、Chrome Android 等）。如果你有本地推理需求，可以在桌面端配合 Ollama 等本地模型使用，但扩展本身没有移动版本。

能翻译 PDF 吗？

浏览器内直接打开、由浏览器自身渲染的 PDF 页面可以触发翻译；好翻主要面向 HTML 网页，对于由插件式阅读器或独立 PDF viewer 渲染的内容，可能暂时无法识别。遇到这类情况，把文字复制出来用划词翻译通常是最快的替代方案。

扩展会自动更新吗？

当前以开发者模式手动加载的版本不会自动更新，需要到 Releases 重新下载、覆盖加载。等 Chrome Web Store / Edge / Firefox AMO 上架并签名后，就能通过商店自动更新，无需手动操作。

译文不对，能自己改吗？

可以。鼠标悬停（hover）在任意译文上即可直接编辑；你的修改会被记录下来，扩展还会自动抽取其中的术语，沉淀进你的个人术语表。随着使用，遇到同类表述会越来越贴合你的习惯。

翻译提示 401 / 403 或「额度不足」怎么办？

先检查：设置里填的 API Key 是否有效、有没有多复制了空格或换行、对应服务商账户是否有余额或免费额度。401 / 403 通常是 Key 无效或权限不足；「额度不足」是服务商账户问题，去对应平台充值或换 Key 即可。也可在设置里开启「备用引擎故障转移」，主引擎报错时自动切到备用引擎一次。

怎么切换或添加服务商 / 模型？

打开设置 → 从服务商下拉里选内置的 12 家之一即可；想用列表外的模型，选「任意 OpenAI 兼容接口」并填入 Base URL 与模型名。具体用哪个模型（如 deepseek-chat、gpt-4o）也在设置里选。改完即时生效，无需重载扩展。

术语表在哪看？怎么用？

悬停任意译文即可直接修改，好翻会自动把其中的术语抽出来，沉淀进你的个人术语表；在设置的术语表区域可以查看、编辑、删除已沉淀的术语。开启后，遇到相同表述会优先沿用你的译法，越翻越贴合习惯。术语注入上限（0–60）也能在设置里调整。

划词翻译没出现 / 不工作？

先确认扩展已启用、且当前网站没有被「暂停翻译」。划词翻译依赖选中文字后弹出的圆形按钮，部分网页（如 PDF 阅读器、Canvas 画布）无法选中文本，自然没有浮层；这种情况改用右下角「译」按钮或右键菜单翻译整页。若完全不弹出，尝试重载扩展与页面。

可以完全离线翻译吗？

可以。在设置里选择 Ollama 等本地模型，翻译请求只在你本机处理，完全不出网络，适合对数据最敏感的场景。本地模型的能力取决于你部署的模型大小——轻量模型速度快，但译文质量可能不及云端大模型。

翻译内容会被翻译服务商保存吗？

翻译内容由你选择的第三方服务商处理，是否保存、保存多久、是否用于模型训练，由该服务商的条款与隐私政策决定，好翻无法替它们承诺。因此建议：① 重要或敏感内容优先选用你信任的服务商；② 数据最敏感的场景用 Ollama 本地模型，内容完全不出本机。

术语表和设置能跨设备同步吗？

不能。好翻没有账号体系，术语表、译文编辑记录与所有设置都只保存在当前设备的浏览器本地（storage.local），不会上传云端，因此也不支持多设备同步。这也是「本地优先、数据主权在你手里」的一部分——想在新设备上复用，需要重新配置。

为什么有的译文带「已校正」标记？

那是「翻译质量自检」在起作用：译文生成后，好翻会校验原文中的数字、网址、邮箱、占位符与代码符号有没有被漏掉或改坏；一旦发现缺失，会自动追加保真指令重译一次，并在界面上标记「已校正」，提醒你这段译文被额外修正过。

好翻和沉浸式翻译等同类工具有什么区别？

两者都做「原文 + 译文」的沉浸式对照阅读，但定位不同。好翻强调：免 Key 就能体验（Google 翻译免 Key 通道）、本地优先（无账号、无遥测、数据不出浏览器）、可接任意 OpenAI 兼容接口与本地模型（Ollama）、译文可编辑 + 术语自学习、全程开源（MIT）。沉浸式翻译是成熟的商业产品，功能面更广（PDF、视频、更多第三方集成等）。选哪个取决于你更看重「数据自主与可定制」，还是「开箱即用的完整生态」。

会上架哪些应用商店？

计划上架 Chrome Web Store、Edge 加载项商店与 Firefox AMO，提交清单已整理在仓库 docs/STORE_SUBMISSION.md。上架并签名后即可在商店一键安装、自动更新；在上架完成前，请按安装指南手动加载。

遇到问题或想提建议，去哪反馈？

欢迎到 GitHub Issues 反馈：描述复现步骤、浏览器版本与所选服务商，我们会在能力范围内尽快处理。功能建议、翻译质量案例（附原文与译文对照）也很有价值，能帮我们定位是提示词、引擎还是渲染层的问题。
