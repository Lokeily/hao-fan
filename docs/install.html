Chrome · Edge

Chrome 与 Edge 安装（MV3）

下载并解压 ZIP

点击上方「Chrome / Edge 版」按钮，将下载得到的 open-translator-cn-x.x.x-chrome.zip 解压到一个长期保留的目录（不要放在下载文件夹后删除，浏览器会持续引用该目录）。

打开扩展管理页

在地址栏输入并访问：

chrome://extensions

Edge 用户请访问 edge://extensions。

开启开发者模式

在扩展管理页右上角（Edge 为左侧）找到「开发者模式」开关并打开。

加载已解压的扩展程序

点击左上角出现的「加载已解压的扩展程序」按钮，选择解压后直接包含 manifest.json 的那一层目录。成功后列表会出现「好翻」，浏览器右上角工具栏可将其固定。

Firefox

Firefox 安装（MV2）

下载 Firefox 版 ZIP 并解压

使用上方「Firefox 版」按钮下载，解压备用。

打开调试页

about:debugging#/runtime/this-firefox

在 Firefox 地址栏输入以上地址并访问。

临时载入附加组件

点击「临时载入附加组件…」，选择解压目录中的 manifest.json 文件（注意是文件不是目录）。工具栏出现「好翻」图标即成功。

⚠️ Firefox 的「临时载入」为平台限制：重启浏览器后扩展会消失，需重新载入一次。签名版与商店上架正在推进中。
Setup

首次配置：三十秒开始翻译

打开设置

任意网页右下角会出现蓝色「译」按钮组，点击旁边的 ⚙ 齿轮打开快速设置面板，再点「打开完整设置」（或点浏览器工具栏的好翻图标 → 设置）。

选择引擎并填入 API Key

推荐 DeepSeek / 智谱 GLM 等国内服务商（注册即送额度）。粘贴 Key 后点击「测试连接」确认可用。

没有 Key？装完即用免 Key 体验

默认引擎 MyMemory 零配置、装完就能翻译；无需任何注册即可立刻体验完整功能。正式使用时建议换回带 Key 的 AI 引擎获得更高质量。

开始阅读

回到任意英文网页，点右下角「译」。译文会逐段出现在原文下方。按 Alt+T 也可一键触发。

Troubleshoot

疑难排查

点了「译」没有任何反应？
① 检查是否处于「手动模式」——该模式整页不自动翻译，需点击段落或划词；② 若弹出引导卡说明还没配置 Key，按提示完成即可自动续译；③ 扩展更新后请在扩展管理页点「重新加载」，并刷新网页。
提示「请先填写 API Key」或测试连接失败？
确认所选服务商与 Key 匹配（不同服务商 Key 不通用）；从服务商后台完整复制，避免多余空格；账户需要有余额或免费额度。401 = Key 无效/过期，403 = 无权限或欠费。
某些页面没有出现「译」按钮？
Chrome 商店页、PDF 查看器等浏览器内部页面禁止注入扩展脚本，属平台限制；此类页面可在弹窗中使用文本翻译替代。另外若该站点被你暂停过，请在弹窗中恢复「当前网站翻译」开关。
升级新版本要注意什么？
覆盖解压到同一目录后在扩展管理页点「重新加载」即可，设置与缓存都会保留。若大版本升级后行为异常，可在设置中导出备份 → 清空存储 → 导入恢复。
如何彻底卸载？
扩展管理页移除即可清除全部本地数据（Key、缓存、历史）。如需保留配置，先在设置页导出备份。
