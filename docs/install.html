三步开始使用

下载对应浏览器的安装包，以「加载已解压的扩展程序」方式安装即可。配置好翻译服务就能用。

先下载安装包

从 Releases 页面下载对应浏览器的 ZIP 并解压到本地。

1

下载安装包

前往 Releases 页面，下载对应浏览器的 ZIP 并解压到本地文件夹。

2

加载扩展

Chrome / Edge 打开 chrome://extensions（Edge 为 edge://extensions），开启「开发者模式」后「加载已解压的扩展程序」。

3

配置并翻译

点击工具栏「好翻」图标 → 设置里选服务商、填 API Key、设目标语言，回到网页点右下角蓝色「译」按钮即可。

首次配置（30 秒）

加载完成后，先告诉好翻用哪个翻译服务。

1

打开设置

点击工具栏「好翻」图标 →「设置」。

2

选服务商、填 Key

选择服务商，填写 API Key 与目标语言；不确定就先选「Google 翻译（免 Key）」。

3

测试并开始

点「测试连接」确认可用，回到网页点击右下角蓝色「译」按钮即可开始；翻译中再点一次可取消。

各浏览器入口

不同浏览器的加载页面略有差异。

Chrome

地址栏输入 chrome://extensions → 右上角开启「开发者模式」→「加载已解压的扩展程序」→ 选择解压后的文件夹。

Edge

地址栏输入 edge://extensions → 左下开启「开发人员模式」→「加载解压缩的扩展」→ 选择解压后的文件夹。

Firefox

地址栏输入 about:debugging#/runtime/this-firefox →「临时载入附加组件」→ 选择解压文件夹中的 manifest.json。

也可在支持的应用商店中搜索安装（以实际上架情况为准）。开发者模式加载的扩展在浏览器重启后可能需要重新加载。

常见问题

装好之后遇到的小状况。

安装后工具栏看不到图标？

部分浏览器默认把扩展收进工具栏的「拼图」菜单里，点击拼图图标把「好翻」固定到工具栏即可。

翻译没反应？

先确认在设置里已选择服务商并正确填写了 API Key 与模型；若用 Google 翻译（免 Key），请留意它可能限流或临时不可用。

浏览器提示「加载失败」？

请确认选择的是解压后的文件夹，且其中包含 manifest.json；若只选中了 ZIP 本身会加载失败。

重启浏览器后扩展没了？

以开发者模式/临时加载方式安装的扩展，在部分浏览器重启后需要重新加载一次。如需长期稳定使用，建议等待应用商店上架后从商店安装。
