开始安装

📥 下载与加载

第一步：拿到安装包；第二步：按浏览器加载。

1

下载安装包

打开 Releases，下载对应浏览器的 ZIP 并解压。

2

Chrome / Edge

访问 chrome://extensions（Edge 为 edge://extensions）→ 开启「开发者模式」→「加载已解压的扩展程序」→ 选择解压后直接包含 manifest.json 的目录。

3

🦊 Firefox

访问 about:debugging#/runtime/this-firefox →「临时载入附加组件」→ 选择解压目录中的 manifest.json。Firefox 未签名扩展在浏览器重启后会消失，属浏览器限制。

Chrome / Edge 基于 MV3；Firefox 以 MV2 临时载入方式运行。商店上架完成后即可获得自动更新，无需手动覆盖安装。

三分钟上手

🚀 快速开始

三步开始你的第一段对照翻译。

1

打开设置

点击工具栏「好翻」图标 → 打开「设置」。

2

配置服务商

选择服务商，填写 API Key，设置目标语言，点击「测试连接」确认可用。

3

开始翻译

回到网页，点击右下角蓝色「译」按钮开始翻译；翻译中再次点击可取消。

想先体验？在设置中选择「Google 翻译」即可免 Key 使用。

遇到问题

⚙️ 加载后常见问题

手动加载偶尔会踩几个小坑，先对照排查，多半能立刻解决。

选错目录

「加载已解压的扩展程序」时，务必选择直接包含 manifest.json 的文件夹。如果选了外层解压目录，扩展会报错或不显示图标。

Firefox 重启后消失

这是 Firefox 对未签名扩展的限制（临时载入会在重启后被清除），不是扩展问题。等 AMO 上架签名后即可常驻，期间重启后重新载入一次即可。

图标是灰的 / 点不动

确认开发者模式已开启，且扩展未被浏览器自动禁用；若被禁用，在扩展管理页手动「启用」即可。也别忘了先在设置里配置好服务商与 Key。

下一步

👉 装好后，下一步做什么

扩展加载成功只是开始。按顺序走完下面两步，你就能翻出第一段对照译文。

1

先配置服务商

点工具栏「好翻」图标 → 打开「设置」，选一个服务商并填好 Key（想免费用就选 Google 翻译）。这一步决定了译文从哪来、花不花钱。

2

点「译」开始翻译

回到网页，点右下角蓝色「译」按钮；想逐句看就用划词翻译，想整页对照就读沉浸式双语。翻译中再点一次「译」可取消。

不知道填哪个服务商、Key 在哪申请？看翻译服务页，有每家服务的定位和配置说明。

商店版

🏪 商店上架

更省心的安装方式正在路上。

Chrome Web Store / Edge / Firefox AMO 的提交清单已整理在仓库 docs/STORE_SUBMISSION.md。 上架后即可在商店内一键安装并获得自动更新，无需再手动覆盖安装。

在商店上架前，手动加载版不会自动更新：想升级时，到 Releases 下载新版 ZIP，解压后在同一目录「覆盖加载」即可（Chrome / Edge 在扩展管理页点「刷新」图标，Firefox 重新「临时载入」）。
