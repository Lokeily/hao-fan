它是怎么工作的

三步，把外文网页变成中英对照——全程只在你这台设备上按需发生。

1

触发翻译

点击右下角蓝色「译」按钮、使用快捷键，或在选中文字后通过右键菜单「翻译选中文字」发起。好翻只在当前标签页按需工作（activeTab 权限），不会后台扫描页面。

2

抽取与对照

内容脚本读取页面可见文本、按段落拆分，通过 Shadow DOM 把译文渲染到原文下方。原网页布局与脚本不被破坏，译文随滚动自然跟随。

3

翻译与缓存

文本发往你配置的翻译服务；本地缓存命中则直接返回译文，省时也省 Token。选择 Google 翻译（免 Key）模式时，连 API Key 都不需要。
