✨ 基本功能

好翻做的事其实很纯粹：保留网页原文，把译文自然地嵌在原文下方，让你边读边对照。下面是它最核心的几项能力。

沉浸式双语对照

原文保留，译文显示在原文下方，随页面滚动自然跟随，对照阅读不打断思路。

流式输出

首段边生成边显示，首字延迟低至毫秒级（基线实测约 90ms），长文也不干等。

上下文感知翻译

结合页面标题与前段译文，长文代词指代与术语更连贯，不会翻着翻着「他」变成「它」。

划词翻译

选中文字即译，独立浮窗展示，不改变原网页；顺手查词、查句都方便。

译文可编辑 · 术语自学习

hover 译文即可修改，自动抽取术语沉淀进个人术语表，越翻越贴合你的用语习惯。

多引擎任选

多家 AI 与传统翻译预设开箱即用，也支持任意 OpenAI 兼容接口与本地模型，质量、成本、隐私由你权衡。

⌨️ 怎么用

不用学新工具——好翻把翻译揉进你本来就有的阅读动作里，几种方式随手切换。

划词即译

选中网页上的任意词或句，独立浮窗就地给出译文，原页面一字不动，查词查句都顺手。

悬停段落

快捷键在原文下方显示译文，专注沉浸式双语阅读，不打断、不跳转、不遮挡。

整页一键对照

一键把整页切换为双语并排，或随时退回仅原文 / 仅译文；快捷键随时开关，长文阅读的节奏你定。

多引擎路由

按场景切 AI / 传统 / 本地模型：长文要质量用 AI，随手查用传统，敏感内容走本地。

💎 为什么选「好翻」

比起「一键整页替换」的翻译器，好翻把选择权交还给你。

01

对照阅读，不是覆盖阅读

译文嵌在原文下方，而不是把整页换成看不惯的译文。你始终知道「原文说了什么」，遇到存疑的翻译也能立刻回看。

02

数据主权在你手里

没有账号、没有遥测、没有广告追踪。API Key 只存本地，翻译请求直连你选的服务商，我们看不到、也不收集你的任何数据。
