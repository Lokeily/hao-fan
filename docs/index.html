FAQ

常见问题

好翻真的完全免费吗？
扩展本身 MIT 开源、永久免费、无任何功能限制。翻译消耗由你自己的服务商账户承担；不想花钱可以选内置免 Key 通道（MyMemory）体验，或用 Ollama 本地模型实现零成本。
我的浏览内容和 API Key 安全吗？
Key 只存本机浏览器，直连所选服务商，不经过任何第三方服务器；扩展自身零遥测。详见隐私政策。
和「沉浸式翻译」这类产品有什么区别？
核心差异在架构：多数产品经厂商服务器中转且闭源；好翻是直连架构 + 完整开源。完整对比见差异化页面。
会大量消耗 Token 吗？
五层省钱机制：句子级缓存、30 天整段缓存、术语库命中、目标语言跳过、动态冷却。还有手动模式点哪译哪。首次翻译后重复阅读几乎零消耗。
为什么安装后没有自动更新？
开发者模式加载的未签名包不会自动更新——平台限制。请关注 Releases 页面；商店上架推进中。
