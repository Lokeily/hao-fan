FAQ

常见问题

好翻真的完全免费吗？
扩展本身 MIT 开源、永久免费、无任何功能限制。翻译消耗由你自己的服务商账户承担；不想花钱可以选内置免 Key 通道（MyMemory）体验，或使用 Ollama 本地模型实现零成本。
我的浏览内容和 API Key 安全吗？
Key 只存本机浏览器，直连所选服务商，不经过任何第三方服务器；扩展自身零遥测。详见隐私政策。
与「沉浸式翻译」这类产品有什么区别？
核心差异在架构：多数产品经厂商服务器中转且闭源；好翻是直连架构 + 完整开源。完整对比见差异化页面。
会大量消耗 Token 吗？
五层省钱机制：句子级缓存、30 天整段缓存、术语库命中、目标语言跳过、动态冷却。另有手动模式，点哪段译哪段。首次翻译后重复阅读几乎零消耗。
图片翻译怎么用？
右键网页图片选「好翻翻译此图片」，或在弹窗上传本地图片。需要支持视觉的模型（GPT-4o / GLM-4V / 混元 Vision / 千问 VL 等）或本机 Ollama（免 Key 视觉方案）；译文直接画在图上，可导出 PNG、悬停对照原文。发图时会自动切换到该厂商的视觉模型，无需手动改配置。
为什么安装后没有自动更新？
开发者模式加载的未签名包不会自动更新——平台限制。请关注 Releases 页面；Chrome Web Store / Edge / Firefox AMO 商店上架正在进行中。
