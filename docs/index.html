关于好翻

「好翻」是一款浏览器翻译扩展：它保留网页原文，把译文自然地显示在原文下方，让你逐段对照阅读——而不是把整页换成看不惯的译文。

无论是读论文、看文档，还是逛外语论坛，好翻都帮你「原文 + 译文」并排理解。它不替你决定看什么，只让你两种语言都能读懂；翻译底层用的是你自己的账号与额度，密钥只留在本地，请求直连服务商，我们不做任何中转。

谁在用「好翻」

只要你需要读懂外语网页，好翻就能派上用场。下面是几类最典型的用户。

科研人员与学者

读英文论文、综述与 arXiv 预印本不再头疼；长文结合上下文更连贯，专业术语还能沉淀进个人术语表，越用越顺手。

开发者与工程师

啃官方文档、RFC、Stack Overflow 与 GitHub Issue；代码块、变量名与 URL 原样保留，只翻译真正的自然语言。

跨境电商与外贸

看竞品落地页、海外买家留言与平台政策，快速理解要点；多服务商任选，旺季也不怕单点限流。

留学生与语言学习者

原文 + 译文并排，边读边学地道表达；划词即译、hover 可改，是沉浸式的「随身外教」。

资讯与内容爱好者

逛 Hacker News、Reddit、外语博客与新闻站，不错过任何一场讨论；流式输出让你边翻边读，不用干等。

产品与行业调研

读海外用户反馈、行业报告与竞品动态，快速提取关键信息；本地模型选项更适合处理内部敏感资料。

沉浸式双语对照

原文保留，译文显示在原文下方，随页面滚动自然跟随，对照阅读不打断思路。

流式输出

首段边生成边显示，首字延迟低至毫秒级（基线实测约 90ms），长文也不干等。

上下文感知翻译

结合页面标题与前段译文，长文代词指代与术语更连贯，不会翻着翻着「他」变成「它」。

划词翻译

选中文字即译，独立浮窗展示，不改变原网页；顺手查词、查句都方便。

译文可编辑 · 术语自学习

hover 译文即可修改，自动抽取术语沉淀进个人术语表，越翻越贴合你的用语习惯。

节省 Token

句子级缓存、重复文本合并、术语库命中零请求、目标语言跳过、术语注入上限可调，省额度更省钱。

安装与上手

从 Releases 下载对应浏览器的安装包，手动加载即可。三步开始你的第一段对照翻译。

1

下载安装包

打开 Releases，下载对应浏览器的 ZIP 并解压。

2

加载扩展

Chrome / Edge 开启开发者模式后「加载已解压的扩展程序」；Firefox 在调试页临时载入。

3

配置并翻译

在设置里选择服务商、填写 API Key、设好目标语言，点「译」按钮开始翻译。
