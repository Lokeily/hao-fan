逐项展开说说

① 数据主权：直连不是营销词，是架构

「直连」意味着好翻的代码里根本没有「中转服务器」这个角色。扩展从你的浏览器直接向所选服务商发起 HTTPS 请求——你在设置里选了 DeepSeek，请求就只发往 api.deepseek.com；选了本地 Ollama，则连网络都不出。

  • API Key 经 cleanSecret 净化后仅通过 Authorization 头传输，绝不出现在 URL 中
  • 待译文本用「数据边界」包裹 + 注入护栏，恶意网页无法借翻译操纵指令
  • 这一切不需要信任任何承诺——源码就在仓库里，欢迎审计

② 成本模型：把定价权还给你

云端产品的免费额度是获客成本，最终以订阅费收回。好翻没有服务器要养，所以永远不设额度：

  • 用量 = 你自己的 API 账单，明码标价、随时可停
  • 五层缓存机制让重复阅读几乎零消耗
  • Ollama 本地模型路线：零外部成本、断网可用

③ 开源可审计：信任建立在代码上

隐私声明谁都会写，但只有开源能让你亲自验证。91 项单元测试 + 77 项浏览器回归守护每一个安全声明：

  • 全仓零 innerHTML：译文一律 textContent + Shadow DOM，无 XSS 面
  • Prompt Injection 双层防护有专项测试锁定行为
  • CI 流水线公开运行，每次提交可复查构建产物

④ 公平的比较

我们也客观说明另一面：闭源产品通常开箱即用、商店一键安装且有商业客服；好翻目前需要手动加载并自配 Key，上手门槛略高。如果你在意的是数据掌控、成本自由与透明度，好翻值得这三十秒的安装过程；如果更看重省事，也请至少关注一下你正在使用的产品如何处理你的数据。
