首页/功能

为「读外文网页」而生

从整页对照到划词翻译，所有能力都围绕一个目标：让你读得更顺、更省心。

翻译体验

把译文自然地放进原文的阅读流里。

沉浸式双语对照

原文保留，译文自然显示在原文下方，随页面滚动一起跟随，不打断阅读节奏。

可见区域优先

先翻译当前屏幕里的内容，滚动时再继续翻译新出现的段落，首屏更快出结果。

动态内容翻译

弹窗、下拉菜单、无限滚动等异步加载的内容会自动补译，单页应用也不漏。

划词翻译

选中网页上的文字即译，独立浮窗展示，不改变原网页结构。

图片翻译

网页图片与本地图片支持 OCR 识别后翻译（需配置支持视觉能力的模型）。

按网站暂停

一键暂停当前网站的译文、清理页面，无需刷新即可恢复，互不干扰。

怎么发起翻译

四种入口，怎么顺手怎么来。

悬浮「译」按钮

网页右下角的蓝色「译」按钮是主入口；翻译过程中再次点击即可取消。

快捷键触发

默认快捷键可一键对当前页面发起翻译，手不离键盘也能用。

右键菜单

选中文字后右键「翻译选中文字」，直接对选中内容发起划词翻译。

设置内测试连接

填好服务商与 Key 后，点「测试连接」即可确认配置可用，再回到网页翻译。

智能与效率

少花钱、少等待，把重复劳动交给本地缓存。

节省 Token

本地缓存、重复文本合并、术语库命中零请求、目标语言自动跳过，少花钱也更快。

译文本地缓存

已翻译文本以哈希键保存在本地，默认保留 30 天、最多 2000 条，相同内容不再重复请求。

自定义术语表

把专有名词、品牌名固定成你想要的译法，命中即直接采用，不再占用请求额度。

隐私与安全

能不收集就不收集，必须用的数据只存在你本地。

提示词注入防护

待译文本被明确包裹并标记为「数据而非指令」，降低恶意网页夹带指令操纵译文的风险。

API Key 本地隔离

不同服务商的密钥分别存储，仅随对应服务的请求发送，不会出现在其他请求里。

不使用远程代码

所有逻辑都打包在扩展内，运行时不从外部下载并执行任何 JavaScript，配合严格 CSP。

高度自定义

服务商、模型、提示词、术语表、翻译风格，怎么顺手怎么来。

自由配置引擎

服务商、模型名称、Base URL、API Key 全部可改；支持任意 OpenAI 兼容接口与本地模型。

自定义提示词与风格

可写入自己的系统提示词，调整翻译语气与风格，适配不同场景与文体。

多语言与目标跳过

源语言、目标语言可设；当页面语言已是目标语言时自动跳过，避免无意义翻译。
