✨ 功能特性

好翻做的事其实很纯粹：保留网页原文，把译文自然地嵌在原文下方，让你边读边对照。它不替换你眼前的页面，而是把翻译揉进你本来就有的阅读动作里。下面把这件事拆开讲——先说它「怎么做到」，再按五个主题列出 17 项已经写进代码、随每个版本一起发布的真实功能。

🧩 它怎么做到「对照不卡、译文不乱」

好翻不是把整页丢给翻译接口那么简单。下面六点，是它「读着顺、翻得准、还不泄密」的底层支撑，每一项都对应仓库里的具体实现。

双层架构

内容脚本负责页面注入与渲染，后台 Service Worker 负责密钥管理与翻译调用，二者通过消息与持久端口通信，贴合 Manifest V3 的生命周期约束。

流式回填

长文本经 SSE 长连接返回，首段边生成边回填到对应节点，逐字浮现；你不必等整段翻译完才开始读。

注入防护

网页标题、前文等不可信内容，被显式降级为「数据而非指令」，追加到用户消息末尾，而不是塞进系统提示词，降低恶意页面操纵译文的风险。

译后自检

译文生成后会校验原文中的数字、网址、邮箱、占位符与代码 token 是否完整保留；一旦缺失，自动追加保真指令重试校正，并在界面上标记「已校正」。

省 Token 策略

句子级缓存、重复文本合并、术语库命中零请求、目标语言跳过、术语注入上限可调——多层叠加，显著降低调用成本与等待。

稳健渲染

用 MutationObserver 主动排除自身注入节点以防递归；译文统一用 textContent 注入防 XSS；后台断连时回退首段，避免页面空白。

📖 对照与阅读体验

这一类解决一个最朴素的问题：怎么让你「读得下去、又看得回原文」。它们决定了好翻用起来是不是顺手。

沉浸式双语对照

译文以一段段对照的方式嵌在原文下方，你既能读译文，也随时能回看原文。普通排版、Flex、Grid 布局都做了适配，不会出现重叠或错位。

流式输出

长文经 SSE 长连接流式返回，首段边生成边显示，首字延迟低至毫秒级（基线实测约 90ms）。不用盯着空白等整段翻译完。

上下文感知翻译

好翻会把当前页面标题、紧邻的前一段译文作为上下文传给模型，长文中「他 / 她 / 它」「这个 / 那个」的指代更连贯，术语也更统一。

可见区域优先

不一次性翻译整页。先翻你正在看的屏幕内容，向下滚动时再翻译新进入视口的部分，首屏更快出结果，长文也不卡。

动态内容翻译

网页里的弹窗、下拉菜单、无限滚动加载的新内容，好翻都会自动重新扫描并补译，单页应用（SPA）也不在话下。

✅ 翻译质量

机翻最怕「数字翻错、网址丢一半、术语前后不一」。好翻把这类细节当成一等公民来对待。

翻译质量自检

译文生成后会自动检查：数字、网址、邮箱、占位符、代码符号有没有被漏掉或改坏。发现缺失就追加保真指令重译一次，并在界面上标记「已校正」。

译文可编辑 · 术语自学习

鼠标悬停任意译文就能直接改；好翻还会自动把里面的术语抽出来，沉淀进你的个人术语表。术语越用越贴合你的用语习惯。

划词翻译

在网页上选中任意词或句子，旁边立刻出现翻译浮层；原网页一字不动，查词、查句都顺手。

⚙️ 性能与引擎

翻译的「快慢」和「贵不贵」，很大程度取决于引擎怎么调度。好翻把调度权交给你。

多引擎路由

主引擎限流、报错（如 401 / 403 / 额度）时，自动切到备用引擎一次；单段超过约 1800 字，自动改用你设定的「长文强模型」。设置里都能配。

节省 Token

多层省钱：句子级缓存命中 0 消耗、重复文本合并、术语库命中零请求、目标语言直接跳过、术语注入上限可调（0–60，默认 24）。省钱又提速。

图片翻译

右键网页图片、或上传本地图片，好翻会用支持视觉的模型做 OCR 识别并翻译，结果以覆盖层或独立结果页呈现（需视觉模型）。

🤝 便捷与交互

好的翻译器应该「待在角落、随叫随到」。这些能力让你几乎感觉不到它的存在，却又处处用得上。

按网站暂停

在某个网站不需要翻译时，一键暂停并清理译文；想恢复时也不用刷新页面，状态即时切换。

可拖动工具栏

网页右下角的「译 + 设置」悬浮按钮组可以拖到屏幕任意位置，位置会自动记住，下次打开还在。

页面内快速设置

不用离开网页，点一下齿轮就弹出设置浮层：改语言、换引擎、暂停当前网站，改动即时落盘生效。

翻译进度显示

翻译进行时有状态条实时显示「已译 N / 共 M 段」，并带旋转加载指示，长文翻译不再「不知道进行到哪了」。

键盘快捷键

按下 Alt+T 直接翻译当前网页；快捷键也能在浏览器设置页里自定义成你顺手的键位。

🎛️ 自由配置

好翻的默认参数已经够用，但它不替你做主。几乎所有环节都能按你的需求调整。

自定义能力

服务商、模型、Base URL、系统提示词、术语表、翻译风格……几乎所有环节都能配置，即存即用。

任意 OpenAI 兼容接口

除了内置的 12 家服务，你也可以填任意兼容 OpenAI 协议的端点与 Base URL，接上你自己的网关或私有部署。

本地模型（Ollama）

把翻译留在你自己的机器上：接入 Ollama 等本地模型，敏感内容完全不出本机，适合对数据最在意的场景。

💡 不只是「翻译」，更是「读得懂」

两个最能体现好翻差异化的能力，用真实的网页样貌给你看。

沉浸式对照，不是整页替换

译文嵌在原文下方，而不是把整页换成看不惯的译文。你始终知道「原文说了什么」，遇到存疑的翻译也能立刻回看原文。代码、变量名、公式这些不该翻的东西，好翻会原样保留。

arxiv.org/abs/2406.12345

We propose a lightweight architecture that reduces latency…

我们提出了一种轻量级架构，可降低延迟……

译文可改，术语自学习

鼠标悬停任意译文即可直接修改；好翻会自动抽取其中的术语，沉淀进你的个人术语表。术语越用越贴合你的用语习惯——团队的黑话、行业的标准译法，都能慢慢「教会」它。
