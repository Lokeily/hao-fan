这些能力都不是演示稿里的「规划」，而是已经写进代码、随每个版本一起发布的真实功能。下面按五组细分：① 双语对照与流式输出　② 上下文感知与质量自检　③ 划词翻译与译文可编辑　④ 性能优化与多引擎路由　⑤ 设置项与快捷键——方便你对号入座。

沉浸式双语对照

原文保留，译文显示在原文下方，随页面滚动自然跟随。

流式输出

首段边生成边显示，首字延迟低至毫秒级（基线实测约 90ms）。

上下文感知翻译

结合页面标题与前段译文，长文代词指代与术语更连贯。

翻译质量自检

数字 / URL / 代码 token 保真校验，缺失自动校正并标记提示。

可见区域优先

先翻译当前屏幕内容，滚动时继续翻译新出现的内容。

动态内容翻译

弹窗、菜单、无限滚动等异步加载的内容自动补译。

划词翻译

选中文字即译，独立浮窗展示，不改变原网页。

译文可编辑 · 术语自学习

hover 译文即可修改，自动抽取术语沉淀进个人术语表。

图片翻译

网页图片与本地图片 OCR + 翻译（需支持视觉的模型）。

按网站暂停

一键暂停当前网站、清理译文，无需刷新即可恢复。

多引擎路由

备用引擎故障转移（限流/报错自动切换）+ 长文强模型路由。

节省 Token

句子级缓存、重复文本合并、术语库命中零请求、目标语言跳过、术语注入上限可调。

可拖动工具栏

「译 + 设置」悬浮按钮组可拖到任意位置，位置自动记忆。

页面内快速设置

齿轮按钮弹出悬浮设置窗：语言 / 引擎 / 暂停本站即改即生效。

翻译进度显示

状态条实时显示已译 X/Y 段，加载态带旋转指示。

键盘快捷键

Alt+T 直接翻译当前网页（浏览器设置页可自定义）。

自定义能力

服务商、模型、Base URL、提示词、术语表、翻译风格均可配置。
