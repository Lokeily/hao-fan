Features

每一项功能，都为「读懂」服务

📖 核心翻译体验

沉浸式双语对照

原文原封不动，译文以独立节点贴在每段正下方（Shadow DOM 隔离），随页面滚动自然跟随。

  • 双栏 / 多列 / 网格卡片布局中，译文始终留在各自栏内，不串位
  • 无语义块的纯文本容器按行拆分，每行译文紧跟对应原文行
  • 四种显示样式可切换：默认 / 蓝色虚线 / 下划线 / 高亮块
  • SPA 动态内容自动补译：弹窗、无限滚动、Tab 显隐都能跟上

流式输出 · 首字即显

划词、悬停、点段落、输入框四处交互全部走 SSE 长连接逐字回填，首字毫秒级出现。

  • 15 秒空闲超时兜底；通道异常自动回退普通请求，保证不漏译
  • 放弃等待时主动通知后台取消生成，同一文本绝不双份计费
  • 整页翻译仍走批量协议：一次请求译多段，比逐条流式省得多

划词 · 悬停 · 输入框，三处即译

覆盖所有阅读场景的即译入口，结果浮层统一支持复制与朗读。

  • 划词：选中文字出现圆形「译」按钮，结果浮层带原文对照
  • 悬停：段落停留 500ms 出气泡，可固定钉住慢慢读
  • 输入框：聚焦即出按钮，译文浮层便于写邮件 / 发帖前润色
  • 手动模式下点击段落直接翻译，整页零打扰

图片翻译

右键网页图片或上传本地图片，视觉模型 OCR 识别文字区域并叠加译文色块。

  • 漫画、截图、图表里的文字都能读出来并翻译
  • 结果面板列出全部文字段，支持开关叠加层对照原图
🧠 智能与质量

上下文感知翻译

结合页面标题与前一段译文的滑动窗口，让模型像读过全文一样下笔。

  • 长文的代词指代（it / they / 该方法）前后一致
  • 跨段术语口径统一，不会一段一个叫法
  • 上下文作为「数据」注入用户消息而非系统提示，防页面标题注入攻击

翻译质量自检

译后自动校验关键信息保真度，这是「接近人工翻译」的安全网。

  • 校验数字、URL、邮箱、占位符（%s、{name}）、代码 token 是否保留
  • 缺失时追加保真指令自动校正重试一次，仍缺失则标记 🚩 提示而不误导
  • 比较前做等价归一化：千分位、全角、日期改写不误报

多引擎智能路由

不同场景自动选择最合适的引擎，故障时无缝切换。

  • 主引擎 401/403/限流/额度不足时，按顺序自动切换备用引擎
  • 超过阈值的长文自动路由到「强模型」，短文继续用便宜模型
  • 15 家引擎随时切换，含任意 OpenAI 兼容自建端点

译文可编辑 · 术语自学习

你对译文的每一次修正，都会变成词库里的一条规则。

  • 悬停译文即可编辑，Enter 提交、Esc 还原
  • LLM 对比原文与修改稿，自动抽取术语写入个人词库并即时生效
  • 短术语才入库，避免整句污染词表
✨ v0.2.0 新增

朗读译文（TTS）

划词面板、悬停气泡、输入框结果一键朗读，外语学习与听读场景利器。

  • 按目标语言自动匹配发音，优先在线高质量语音（Edge 神经 / Google 网络）
  • 设置面板可自选朗读人声，跟随配置跨设备迁移
  • 点击切换停止，自然结束自动复位；语速略放缓更清晰
  • 基于浏览器内置语音合成，零依赖、离线可用

翻译历史

弹窗新增「历史」标签页，查过的词句随时找回。

  • 记录划词 / 输入框 / 弹窗三类主动翻译，悬停噪声不入册
  • 关键词搜索、点击回填重译、一键清空
  • 本地存储上限 200 条，同原文+译文去重置顶

设置导出 / 导入

换机迁移、备份恢复，一个 JSON 文件搞定。

  • 引擎、语言偏好、翻译模式、术语表、系统提示词、站点列表全量打包
  • API Key 默认剥离，需要时可显式勾选包含
  • 导入严格校验字段类型，脏数据无法进入存储
💰 五层省 Token 机制
机制原理效果
句子级缓存按句缓存 + 归一化匹配，SPA 微变只重译变化句；缺失句合并为一次批量请求改一句话 ≠ 重付全篇
整段 LRU 缓存相同文本 30 天有效，上限 2000 条，可在设置中清空重复阅读零请求
术语库命中整条命中个人术语表直接返回，不发请求专有名词零 Token
目标语言跳过检测到段落已是目标语言，本地直接跳过并提示杜绝「中译中」
动态冷却 + 数字补丁行情/时钟类元素仅数字变化时就地替换译文数字，8 秒冷却合并抖动高频刷新不再烧钱

另有「手动模式」：整页不自动翻译，点哪段译哪段，Token 开销完全由你掌控。
