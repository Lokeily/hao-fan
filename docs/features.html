Features

每一项功能，都为「读懂」服务

这是好翻 v0.2.16 的全部能力清单——从提取到渲染的完整流水线，四处即译入口，三态阅读模式，以及五层省钱机制。

📖 核心翻译体验

沉浸式双语对照

原文原封不动，译文以独立节点贴在每段正下方（Shadow DOM 隔离），随页面滚动自然跟随。

  • 双栏 / 多列 / 网格卡片布局中，译文始终留在各自栏内，不串位
  • 渲染后几何校验 + 自动降级：多列、浮动、绝对定位场景译文不再漂移
  • 无语义块的纯文本容器按行拆分，且带覆盖率校验——拆不干净就整块翻，宁可少拆也不漏译
  • SPA 动态内容自动补译：弹窗、无限滚动、Tab 显隐都能跟上，8 秒冷却防烧 Token
  • 遵守站点「禁止翻译」标记（translate="no" / notranslate），品牌名和代码串不误译

流式输出 · 首字即显

划词、悬停、点段落、输入框四处交互全部走 SSE 长连接逐字回填，首字毫秒级出现。

  • 15 秒空闲超时兜底；通道异常自动回退普通请求，保证不漏译
  • 放弃等待时主动通知后台取消生成，同一文本绝不双份计费
  • 整页翻译走批量协议：一次请求译多段，比逐条流式省得多

划词 · 悬停 · 输入框，三处即译

覆盖所有阅读场景的即译入口，结果浮层统一支持复制与朗读。

  • 划词：选中文字出现圆形「译」按钮，结果浮层带原文对照
  • 悬停：段落停留出玻璃质感气泡，可固定钉住、可拖拽换位——放到哪就记住哪，下次停在原位
  • 输入框：聚焦即出按钮，译文浮层便于写邮件 / 发帖前润色
  • 手动模式下点击段落直接翻译，整页零打扰

图片翻译：译文直接画在图上

右键网页图片或上传本地图片，译文经 Canvas 擦字重排直接长在图上——海报、截图、商品图翻译后是「一张被翻译过的图」。

  • 三阶段管线：视觉模型 OCR 定位 → 复用完整主管线翻译 → 采样底色擦掉原文、译文按原位重排
  • 字号从大到小自适应塞进原框，CJK 逐字换行 / 拉丁整词换行，按背景明暗自动选黑字或白字
  • 结果页支持「仅译文 / 原文+译文」切换、悬停看原文、一键保存 PNG；刷新页面结果不丢（24 小时保留）
  • 页内右键翻译直接画在网页图片上，图片缩放时自动跟随不错位
  • 视觉模型自动挑选：发图时自动切换到该厂商的视觉模型（GPT-4o / GLM-4V / 混元 Vision / 千问 VL 等），不用手动改配置；Ollama 本地模型是免 Key 视觉方案
  • 图片翻译计入用量统计，月度预算对图片同样生效
🧠 智能与质量

上下文感知翻译

结合页面标题与前一段译文的滑动窗口，让模型像读过全文一样下笔。

  • 长文的代词指代（it / they / 该方法）前后一致
  • 跨段术语口径统一，不会一段一个叫法
  • 上下文作为「数据」注入用户消息而非系统提示，防页面标题注入攻击

翻译质量自检

译后自动校验关键信息保真度，这是「接近人工翻译」的安全网。

  • 校验数字、URL、邮箱、占位符（%s、{name}）、代码 token 是否保留
  • 缺失时追加保真指令自动校正重试一次，仍缺失则标记 🚩 提示而不误导
  • 比较前做等价归一化：千分位、全角、日期改写不误报
  • 纯数字不遮罩：iPhone 15 的「15」原样保留，标题不会缺字
  • 翻译失败不写缓存：失败结果一律不入 30 天缓存池，杜绝「坏缓存」导致该段永远漏译

多引擎智能路由

不同场景自动选择最合适的引擎，故障时无缝切换。

  • 主引擎 401/403/限流/额度不足时，按顺序自动切换备用引擎——单条与批量整页路径都生效
  • 超过阈值的长文自动路由到「强模型」，短文继续用便宜模型
  • 16 项引擎随时切换，含任意 OpenAI 兼容自建端点；免 Key 通道 MyMemory → Apertium 真正兜底

译文可编辑 · 术语自学习

你对译文的每一次修正，都会变成词库里的一条规则。

  • 悬停译文即可编辑，Enter 提交、Esc 还原
  • LLM 对比原文与修改稿，自动抽取术语写入个人词库并即时生效
  • 短术语才入库，避免整句污染词表

中文识别增强 · 杜绝中译中

不该翻的绝不浪费一次请求，也不产生「中文翻译中文」的尴尬。

  • 两字 UI 词与中英混排句不再被误送翻译
  • 检测到段落已是目标语言，本地直接跳过并提示
  • 英 → 法/德/西等拉丁系目标一律送模型，避免「同字母系统」误判整页漏译
✨ 阅读掌控

阅读模式 · 三态切换

工具栏一键循环：对照（原文+译文）→ 只译（沉浸读译文）→ 悬停（鼠标停留才出译文）。

  • 纯显示层切换：不重新翻译、不发请求、不花 Token
  • 切换立即作用于页面上所有已渲染译文
  • 选择持久化，刷新页面后仍保留

默认手动模式 · 点哪译哪

进入网页不再自动整页翻译——点击段落或划词即译，掌控权交还用户（可切回整页自动）。

  • 整页不自动翻译，Token 开销完全由你掌控
  • 右键菜单新增「显示 / 隐藏译文」，0 请求一键切换
  • 划词面板「切换原文/译文」按钮：对照或纯净模式随手换
  • Alt+T 快捷键一键翻译整页（可在浏览器中自定义）

预置样式主题 · 一键统一

译文显示区提供三套预置主题，一套填好五件套，不必逐项手调。

  • 极简无痕：译文与正文融为一体，适合通读
  • 学习对照：原文译文界限分明，适合精读
  • 专注模式：弱化原文突出译文，适合速览
  • 另有四种显示样式：默认 / 蓝色虚线 / 下划线 / 高亮块；选「自定义」可手动微调，任意手改自动回退自定义

失败卡片 · 引擎健康指示

出错不弹窗打断阅读，状态好坏一眼可见。

  • 失败段落就地渲染玻璃小卡：写明失败原因 + 一键「重试」，成功后自动消失
  • 可重试错误不再弹模态框，由卡片就地承担原因与重试
  • 设置页引擎下拉下方实时状态胶囊：免 Key =「装完即用」、已配 Key =「可用」、未配 =「需粘贴 Key」
  • 译文右下角小「译」角标：悬停浮现，点击直达完整设置
🔊 听读与记录

朗读译文（TTS）

划词面板、悬停气泡、输入框结果一键朗读，外语学习与听读场景利器。

  • 按目标语言自动匹配发音，优先在线高质量语音（Edge 神经 / Google 网络）
  • 设置面板可自选朗读人声，跟随配置跨设备迁移
  • 点击切换停止，自然结束自动复位；语速略放缓更清晰

翻译历史

弹窗「历史」标签页，查过的词句随时找回。

  • 记录划词 / 输入框 / 弹窗三类主动翻译，悬停噪声不入册
  • 关键词搜索、点击回填重译、一键清空
  • 本地存储上限 200 条，同原文+译文去重置顶

💰 五层省 Token 机制
机制原理效果
句子级缓存按句缓存 + 归一化匹配，SPA 微变只重译变化句；缺失句合并为一次批量请求改一句话 ≠ 重付全篇
整段 LRU 缓存相同文本 30 天有效，上限 2000 条，可在设置中清空；失败结果一律不写入重复阅读零请求
术语库命中整条命中个人术语表直接返回，不发请求专有名词零 Token
目标语言跳过检测到段落已是目标语言，本地直接跳过并提示杜绝「中译中」
动态冷却 + 数字补丁行情/时钟类元素仅数字变化时就地替换译文数字，8 秒冷却合并抖动高频刷新不再烧钱
