✨ 功能特性

好翻做的事其实很纯粹：把译文自然地嵌进原文里，让你边读边对照。它不替换你眼前的页面，而是把翻译揉进你本来就有的阅读动作里。下面把这件事拆开讲——先说它「怎么做到」，再按主题列出 19 项已经写进代码、随每个版本一起发布的真实功能。

工作原理

🧩 它怎么做到「对照不卡、译文不乱」

好翻不是把整页丢给翻译接口那么简单。一条译文的生产流水线是：标识符遮罩 → 提示词组装 → 引擎路由 → 请求 / 流式 → 译后自检 → 还原占位符 → 渲染 → 缓存。下面八点，是它「读着顺、翻得准、还不泄密」的底层支撑，每一项都能在开源仓库里找到对应实现。

分层架构

内容脚本负责页面提取与渲染，后台 Service Worker 负责密钥管理与翻译调用，设置界面、协议层、核心翻译、渲染层各司其职——完全贴合 Manifest V3 生命周期。

流式回填

划词、悬停、点段落、输入框等单条翻译走 SSE 长连接逐字回填，首字即显；端口异常自动回退普通请求，不漏译不卡死。

注入防护

网页标题、前文等不可信内容，被显式降级为「数据而非指令」追加到用户消息末尾，而不是塞进系统提示词——恶意页面无法操纵你的译文。

译后自检

译文生成后校验原文中的数字、网址、邮箱、占位符与代码 token 是否完整保留；一旦缺失，自动校正重试一次，仍缺失则保留首版并标记提示。

省 Token 经济性

句子级缓存按句归一化、缺失句合并为一次批量请求、30 天 LRU 整段缓存、术语库命中零请求、智能语言跳过、8 秒动态节流、术语注入上限可调——省成了体系。

稳健渲染

译文以 Shadow DOM 隔离宿主样式，统一用 textContent 注入从根上排除 XSS；MutationObserver 排除自身节点防递归，断连自动回退不空白。

安全设计

API Key 仅经 Authorization 头传输、绝不进 URL；全仓零 innerHTML，权限最小化仅申请 4 项且均有明确用例；扩展页面启用严格内容安全策略，禁止远程脚本。

代码 / 库名保护

翻译前先把 useState、react-dom、React 等代码标识符与品牌专名替换为占位符，译后再还原——库名不会变成中文，占位符更短，顺带省 completion Token。

阅读体验

📖 对照与阅读体验

这一类解决一个最朴素的问题：怎么让你「读得下去、又看得回原文」。读起来顺不顺、翻完还能不能对上原文，都取决于这几项。

沉浸式双语对照

译文以独立节点渲染在原文下方（Shadow DOM 隔离站点样式），随页面滚动自然跟随。普通排版、Flex、Grid、双栏、多列布局都做了适配，不会重叠错位。

流式输出

划词、悬停、点段落、输入框等单条翻译走长连接流式回填，首字即显（基线实测约 90ms）；端口异常自动回退普通请求，不漏译。

上下文感知翻译

好翻结合页面标题与前段译文构造滑动窗口，长文里「他 / 她 / 它」「这个 / 那个」指代更连贯，跨段术语也更统一。

可见区域优先

不一次性翻译整页：先翻你正在看的屏幕内容，向下滚动时再翻新进入视口的部分。首屏更快出结果，长文也不卡。

动态内容翻译

弹窗、菜单、无限滚动等异步加载的内容自动补译；8 秒冷却合并抖动，仅数字变化就地更新——行情、时钟类元素不会反复消耗 Token。

智能语言检测

按段落逐段检测语种：已经是目标语言的段落直接本地跳过，消耗 0 Token——绝不会出现「中译中」，翻译更省也更安静。

质量保障

✅ 翻译质量

机翻最怕「数字翻错、网址丢一半、术语前后不一」。好翻把这类细节当成一等公民来对待——翻完还会自己检查一遍。

翻译质量自检

译文生成后会自动检查：数字、网址、邮箱、占位符、代码符号有没有被漏掉或改坏。发现缺失就追加保真指令重译一次，并在界面上标记「已校正」。

译文可编辑 · 术语自学习

鼠标悬停任意译文就能直接改；好翻还会自动把里面的术语抽出来，沉淀进你的个人术语表。术语越用越贴合你的用语习惯。

划词翻译

在网页上选中任意词或句子，旁边立刻出现翻译浮层；原网页一字不动，查词、查句都顺手。

悬停翻译

鼠标悬停段落约 500ms 即显示译文气泡，可固定或取消；命中会话缓存零请求。快速瞄一眼外文段落，不必整页开译。

性能与引擎

⚙️ 性能与引擎

翻译的「快慢」和「贵不贵」，很大程度取决于引擎怎么调度。好翻把调度权交给你——该省的地方自动省，该用强模型的地方自动上。

多引擎路由

主引擎限流、报错（如 401 / 403 / 额度）时，自动切到备用引擎一次；单段超过约 1800 字，自动改用你设定的「长文强模型」。设置里都能配。

节省 Token

省成了体系：句子级缓存按句归一化、缺失句合并为一次批量请求、30 天整段缓存、术语库命中零请求、目标语言本地跳过、8 秒动态节流、术语注入上限可调（0–24，默认 12）。省钱又提速。

图片翻译

右键网页图片、或上传本地图片，好翻会用支持视觉的模型做 OCR 识别并翻译，结果以覆盖层或独立结果页呈现（需视觉模型）。

便捷交互

🤝 便捷与交互

好的翻译器应该「待在角落、随叫随到」。这些能力让你几乎感觉不到它的存在，却又处处用得上——装上就是顺手。

按网站暂停 / 自动翻译

某个网站不需要翻译时，一键暂停并清理译文；也可以记住「总是自动翻译本站」偏好，下次打开页面直接开译。状态即时切换，无需刷新。

可拖动工具栏

网页右下角的「译 + 设置」悬浮按钮组可以拖到屏幕任意位置，位置会自动记住，下次打开还在。

页面内快速设置

不用离开网页，点一下齿轮就弹出设置浮层：改语言、换引擎、暂停当前网站，改动即时落盘生效。

翻译进度显示

翻译进行时有状态条实时显示「已译 N / 共 M 段」，并带旋转加载指示，长文翻译不再「不知道进行到哪了」。

键盘快捷键

按下 Alt+T 直接翻译当前网页；快捷键也能在浏览器设置页里自定义成你顺手的键位。

手动翻译模式

不想整页自动翻？切到「手动点击 / 划词」模式：点哪段译哪段、划哪句译哪句，Token 开销最小，适合只读关键内容的场景。

自由配置

🎛️ 自由配置

好翻的默认参数已经够用，但它不替你做主——服务商、模型、提示词、术语表、译文样式，几乎所有环节都能按你的习惯调。

自定义能力

服务商、模型、Base URL、系统提示词、术语表、翻译风格……几乎所有环节都能配置，改完即存即用，不用重启。

译文显示样式

译文长相你来定：默认 / 蓝色虚线 / 下划线 / 高亮块四种样式，设置页一键切换即生效，长文阅读更跟手。

任意 OpenAI 兼容接口

除了内置的 12 家服务，你也可以填任意兼容 OpenAI 协议的端点与 Base URL——接上自己的网关、代理或私有部署都行。

本地模型（Ollama）

把翻译留在你自己的机器上：接入 Ollama 等本地模型，敏感内容完全不出本机——对数据最在意的场景，这是最稳的选择。

不止于翻译

💡 不只是「翻译」，更是「读得懂」

两个最能体现好翻差异化的能力，用真实的网页样貌来看。

沉浸式对照，不是整页替换

译文嵌在原文下方，而不是把整页换成看不惯的译文。你始终知道「原文说了什么」，遇到存疑的翻译也能立刻回看原文。代码、变量名、公式这些不该翻的东西，好翻会原样保留——文档、论文、代码站都能放心翻。
