🔒 隐私政策

最后更新：2026-08-22

「好翻」（Open Translator CN）是一款开源、免费、直连自选 AI 的浏览器翻译扩展。本政策依据《中华人民共和国个人信息保护法》《中华人民共和国数据安全法》《中华人民共和国网络安全法》及《中华人民共和国未成年人保护法》等中国大陆法律法规制定，以清晰、诚实的方式说明：扩展及其运营方如何对待你的信息、与你选定的第三方服务相关的信息流向，以及你所享有的权利。我们力求措辞准确——不夸大，也不回避。

好翻的运营方为中国大陆境内的个人开发者，主要面向中国大陆用户提供服务。本政策一切以中国大陆法律法规为准。

核心结论：好翻的运营方不在任何服务器上收集、存储或处理你的个人信息，也不出售或共享任何个人信息。扩展运行在你的浏览器本地；翻译内容只会发往你主动选择的翻译服务商，并由该服务商按其自身条款处理。

一、适用范围

本政策适用于：

  • 好翻浏览器扩展：包括其在你设备上的全部功能（整页翻译、划词翻译、悬停翻译、图片翻译、术语表、设置等）；
  • 本官方网站（含文档与下载指引）：本网站为静态页面，不使用 Cookie、不部署统计或广告追踪脚本，也不会向你索取个人信息。

本政策不涵盖你自行选用的第三方翻译服务商，其信息处理由其各自的服务条款与隐私政策约束，请另行查阅。

二、运营方与信息处理者

好翻是由个人开发者以开源项目形式维护的浏览器扩展，源代码托管于 GitHub（仓库：Lokeily/hao-fan），目前未设立独立法人实体。

由于扩展不在任何服务器上收集或处理个人信息（详见下文），运营方通常并不作为翻译内容的「信息处理者」。你的信息主要在自己的设备本地处理，或在你明确指示下交由你选定的第三方服务商处理。若你对本政策或我们的数据处理实践有疑问，可通过文末联系方式与我们沟通。

三、我们收集哪些信息

在服务器层面：我们不收集任何信息。

  • 没有遥测、没有广告追踪、没有用户行为统计；
  • 没有账号体系，不要求注册或登录；
  • 没有自有后端服务器，也没有服务器端日志。

你在使用扩展时产生的所有数据，均只存在于你的设备本地或你选择的翻译服务商处（详见下节）。

四、我们不会自动收集的信息

与许多同类在线服务不同，好翻不通过任何服务器或后端自动收集以下常见信息：

  • IP 地址与地理位置；
  • 设备标识符（如设备 ID、浏览器指纹）；
  • 使用频率、功能使用等使用统计；
  • 崩溃或错误日志（翻译过程产生的错误仅在本机处理，不会上报）；
  • Cookie、像素标签或同类追踪技术（扩展本身不使用，本网站亦不使用）。

上述信息的缺失，正是「运营方不在服务器收集数据」这一结论的直接体现。

五、信息如何处理

翻译内容（网页文本 / 图片）

  • 当你发起翻译时，待翻译的网页文本或图片会直接发送到你在设置中主动选择的翻译服务商（如 DeepSeek、OpenAI、智谱、腾讯混元、Google 翻译等）；
  • 数据经由你配置的 API 端点传输；本项目不参与、不中转、不留存任何翻译内容；
  • 译文与原文仅缓存在你自己的浏览器本地（默认 30 天有效期、容量上限 LRU 2000 条，可在设置中关闭或清空）。

API 密钥

  • 各服务商的 API Key 仅保存在浏览器本地 storage.local，并按服务商隔离存储；
  • Key 仅随对应的翻译请求发送给该服务商，绝不会被发送给我们或任何第三方；
  • 卸载扩展或清除站点数据后，密钥即被删除。

其他本地数据

  • 暂停翻译的网站列表、你自定义的术语表、翻译统计与偏好设置，均只保存在浏览器本地，不会上传；
  • 图片翻译的临时文件存入浏览器 IndexedDB，读取后即删除，最长 24 小时内自动清理。

本网站

本网站为静态托管，不设置 Cookie、不运行分析脚本、不收集表单信息。你通过 GitHub 与我们交互时，相关数据处理遵循 GitHub 的隐私政策。

六、第三方服务

翻译能力由你自行选择的服务商提供。一旦你选用某家服务商，相应的网页内容、图片与 API Key 将按其指令发往该服务商，并受其服务条款与隐私政策约束。不同服务商的数据处理地点、保留期限与合规资质各不相同，请在使用前自行评估。

其中，「Google 翻译（免 Key）」使用的是非官方公开端点，无服务等级保证，可能随时限流或变更，仅建议用于体验；正式使用请配置支持 API Key 的服务。我们对任何第三方服务商的数据处理行为不承担责任。

七、我们不会出售或共享你的个人信息

我们不会出售你的个人信息，也不会出于商业目的将其共享给第三方。由于好翻不在服务器端持有任何个人数据，实际上不存在可供我们对外披露或出售的用户数据。

唯一的数据流出，发生在你主动选择某家翻译服务商之时：对应的翻译内容会按其指令发往该服务商（详见「第三方服务」一节）。这一流向由你的明确选择触发，而非由我们对外披露或共享。

八、法律依据

好翻的「本地优先、直连服务商」架构，与中国大陆现行法律的要求天然一致。依据《中华人民共和国个人信息保护法》等法律法规，处理活动的合法性基础如下：

  • 本地处理：扩展在本地处理你的设置、缓存与术语表，属于为你使用本服务所必需，符合「合法、正当、必要、诚信」原则与最小必要要求；
  • 向服务商发送内容：将内容发送给你所选定的第三方服务商，基于你通过选择服务商并触发翻译而作出的同意，你可随时在设置中更换或停止；
  • 不收集敏感个人信息：我们不收集生物识别、行踪轨迹、金融账户等敏感个人信息，也不存在对其的处理活动。

九、信息存储与保留

  • 所有由扩展产生的数据均存储于你的浏览器本地，由你完全掌控；
  • 翻译缓存默认保留 30 天（容量上限 LRU 2000 条），可在设置中缩短、关闭或手动清空；
  • 卸载扩展、清除浏览器站点数据，或移除对应服务商配置，即可彻底删除相关本地数据。

十、你的权利

依据《中华人民共和国个人信息保护法》，你对个人信息享有查阅、复制、更正、补充、删除的权利，以及撤回同意、要求说明处理规则的权利。由于扩展不向服务器上传任何个人数据，上述权利主要通过「本地数据」方式行使：

  • 查阅、复制、更正、删除：通过扩展设置查看与修改配置、清空缓存 / 术语表，或直接卸载扩展即可完成；
  • 撤回同意：在设置中更换或移除服务商配置、暂停本站翻译，或卸载扩展，即撤回对相应处理活动的同意；
  • 已发送给第三方服务商的数据：请按该服务商的流程向其提出请求；
  • 其他疑问：可通过下方联系方式向我们提出，我们将在不持有数据的前提下尽力协助指引。

十一、Cookie 与类似技术

  • 扩展：好翻扩展不设置或使用任何 Cookie、本地追踪脚本或广告标识符；
  • 本网站：本官方网站为静态托管页面，不设置 Cookie、不运行分析或广告追踪脚本；
  • GitHub：你通过 GitHub 与我们交互时，相关 Cookie 与数据处理遵循 GitHub 的政策；
  • 你可以在浏览器设置中管理或清除网站数据，这不会影响扩展在本地保存的设置与缓存（那些存储在你浏览器本地，由你掌控）。

十二、未成年人保护

好翻并非专门针对未成年人设计，我们亦不主动收集任何人的个人信息（含未成年人）。依据《中华人民共和国未成年人保护法》与《个人信息保护法》关于不满十四周岁未成年人个人信息的规定，我们不会主动收集未满 14 周岁未成年人的个人信息。若我们发现或接到反馈，在未获监护人同意的情况下收集了未成年人的个人信息，将尽力尽快删除。

未满 18 周岁的未成年人在使用本产品及相关服务前，建议在父母或其他监护人的监护与指导下阅读并理解本政策。

十三、安全

  • API Key 等敏感信息仅存于浏览器本地隔离存储，不会被我们获取；
  • 翻译请求按你的配置直连所选服务商，并默认携带注入防护；
  • 扩展页面启用严格内容安全策略，禁止加载远程脚本；译文仅以 textContent 注入，无 XSS 面；
  • 请妥善保管你的 API Key，避免在其所属平台之外泄露。需提醒的是，没有任何传输或存储方式是绝对安全的，我们仅承诺采取与上述设计一致的合理措施；
  • 若发生可能影响你权益的个人信息安全事件，我们将在适用法律要求的范围内，及时通知你及相关监管机构。

十四、第三方链接

本网站可能包含指向第三方网站、浏览器商店、应用商店或你所选翻译服务商页面的链接。第三方网站与服务的隐私实践不由我们控制，建议你在使用或向其提交信息前查阅其隐私政策与服务条款。

十五、本政策的变更

我们可能不时更新本政策以反映功能或合规要求的变化。更新后的版本将发布在本网站相应页面，并以本页顶部的「最后更新」日期标识。

若更新会对你的权利义务产生重大影响，我们将通过项目 Release Notes、仓库说明或其他合理方式予以提示；重大变更可能在扩展内或网站上以公告形式告知。建议你定期查阅。

十六、免责声明

好翻以开源形式「按原样（as is）」提供，不提供担保。在适用法律允许的最大范围内，运营方不对因使用或无法使用本扩展而产生的任何直接或间接损失承担责任。你应自行评估所选翻译服务商的合规性与适用性，并确保你的使用行为符合中华人民共和国法律法规（例如雇主持有设备、企业网络或受监管行业下的使用要求）。本政策为一般性说明，不构成法律意见。

十七、联系我们与投诉渠道

本项目由个人开发者维护，暂未设立独立法人实体；基于「不持有数据」的架构，未单独指定「个人信息保护负责人」，但设有隐私相关沟通渠道：

  • 隐私相关问题：请在 GitHub Issues 提交（注明「隐私」），我们会尽快回复；
  • 向监管机构投诉：如你认为我们未履行个人信息保护义务或侵害了你的合法权益，可向国家互联网信息办公室（网信办）、12321 网络不良与垃圾信息举报受理中心或运营方所在地的相关主管部门投诉、举报；
  • 重要提示：由于我们不在服务器端持有你的个人信息，通常无法代为查询或删除已发送给你所选服务商的数据——请直接向该服务商提出请求。
