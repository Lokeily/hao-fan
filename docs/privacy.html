隐私政策

最后更新：2026 年 8 月 15 日

好翻（Open Translator CN，以下简称「本扩展」）是一款开源的浏览器翻译扩展。本政策说明本扩展在「你的浏览器本地」和「你主动配置的翻译服务」之间如何处理数据。我们的原则很简单：能不收集就不收集，必须用的数据只存在你本地。

一句话总结：本扩展不运营任何服务器，不收集遥测数据，不投放广告，也不追踪你的浏览行为。它只做一件事——把你选中的网页文本，发往你自行选择的翻译服务商。

我们收集哪些信息

本扩展只在你的浏览器本地处理以下数据，不会上传到本扩展作者或任何由本扩展控制的服务器：

  • 配置信息：你选择的翻译服务商、Base URL、模型名称、源语言、目标语言、翻译风格、自定义提示词、术语表。
  • API 密钥：你填写的翻译服务 API Key，按服务商分别保存。
  • 使用统计：本地累计的翻译段数、Token 用量等计数，仅用于扩展内的用量展示。
  • 按网站暂停列表：你选择暂停翻译的网站地址列表。
  • 译文缓存：已翻译的文本，以哈希键存储，默认保留 30 天、最多 2000 条。

我们「不」收集的信息

本扩展不会收集或访问以下数据：

  • 你的精确位置或地理位置；
  • 你的浏览历史记录；
  • 你的键盘输入、鼠标行为等用户活动；
  • 通讯录、消息内容等个人通讯数据（除非你主动选中并翻译了某段文本，该文本才会被发往你选择的翻译服务）；
  • 任何用于广告或跨站追踪的标识符、设备指纹。

数据存储在哪里

上述所有数据均保存在你浏览器的本地存储空间（storage.local）中，不会同步到云端，也不会被本扩展发送到第三方。你可以随时通过浏览器的扩展管理页面清除这些数据，或在扩展设置中关闭译文缓存。

与第三方服务的交互

要实现翻译，本扩展需要向你自行选择并配置的翻译服务商发起网络请求。在此过程中：

  • 被翻译的网页文本和你的 API Key 会通过 HTTPS 加密传输给该服务商；
  • 服务商如何处理这些数据，取决于该服务商自身的隐私政策，本扩展无法控制；
  • 本扩展不会在请求中附加任何追踪标识符、遥测参数或用户标识；
  • 你可以在设置中随时更换服务商或 API Key。

本扩展本身不提供翻译能力、也不中转任何请求——它只是把你配置的凭据和待译文本直连到你选择的服务商。

权限说明

本扩展在浏览器中申请以下权限，且每项权限都仅用于实现翻译功能：

  • storage：在本地保存你的配置、API Key、译文缓存与暂停列表。
  • activeTab：在你主动触发翻译（快捷键、悬浮按钮或右键菜单）时，读取当前标签页的网页文本用于翻译。
  • contextMenus：在右键菜单中添加「翻译选中文字」选项。
  • scripting：在需要时向页面注入脚本，将译文渲染到原文位置，并处理单页应用的动态内容。
  • host_permissions（<all_urls>）：用于向你所选翻译服务的 API 端点发起跨域请求。本扩展仅在翻译时向你明确配置的域名发送数据。

安全与防护

  • 严格内容安全策略：扩展页面使用 script-src 'self'，禁止加载远程脚本或内联脚本，从根源上杜绝远程代码执行。
  • 不使用远程代码：本扩展的所有逻辑都打包在扩展本身，运行时不从外部服务器下载并执行任何 JavaScript。
  • 提示词注入防护：待译文本会被明确包裹并标记为「数据而非指令」，降低恶意网页在文本中夹带指令来操纵译文的风险。
  • API Key 隔离：不同服务商的密钥分别存储，仅随对应服务的请求发送。

你的权利

  • 你可以随时在扩展设置中修改或删除配置、API Key 与术语表；
  • 你可以在浏览器扩展管理页面清除本扩展的全部本地数据；
  • 你可以卸载本扩展，卸载后其本地数据随之一并被清除。

本政策的变更

若本扩展未来改变数据处理方式，我们会更新本页面并在扩展发布说明中提示。本政策仅适用于本扩展本身，不适用于你所选用的翻译服务商。

联系我们

如对本隐私政策有疑问，或发现安全漏洞，请通过 GitHub 仓库 提交 Issue，或按仓库中的 SECURITY.md 私下联系作者。请勿在公开 Issue 中泄露你的 API Key。
