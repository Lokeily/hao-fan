隐私政策

最后更新：2026-08-14

「好翻」（Open Translator CN）是一款开源浏览器翻译扩展。本政策说明扩展收集、使用与存储哪些数据。

我们不收集任何数据：项目没有遥测、广告追踪或用户行为统计；没有服务器端日志，翻译请求不经过任何中转服务器；扩展不注册账号，不要求登录。

我们收集什么

我们不收集任何数据。

  • 项目没有遥测、广告追踪或用户行为统计；
  • 没有服务器端日志，翻译请求不经过任何中转服务器；
  • 扩展不注册账号，不要求登录。

数据处理方式

待翻译的网页内容

  • 整页翻译、划词翻译、图片翻译时，你正在阅读的网页文本（或图片）会直接发送给你在设置页主动选择的翻译服务商（如 DeepSeek、OpenAI、智谱等）；
  • 数据经由你配置的 API 端点传输，本项目不参与、不中转、不存储；
  • 翻译结果与原文仅保存在你自己的浏览器本地缓存中（默认 30 天有效期，可在设置中关闭）。

API Key

  • 各服务商 API Key 仅保存在浏览器本地 storage.local，按服务商隔离；
  • Key 只随你选择的翻译请求发送给对应服务商，扩展不会将其发送给任何其他方；
  • 卸载扩展即清除。

其他本地数据

  • 暂停翻译的网站列表、用户自定义术语表、翻译统计，均只保存在浏览器本地，不会上传；
  • 图片翻译任务临时存入浏览器 IndexedDB，读取后即删除（24 小时内自动清理）。

权限说明

权限用途
storage 保存设置、缓存与本地数据
activeTab / scripting 在你点击翻译时向当前页面注入翻译脚本
contextMenus 提供「翻译本页 / 翻译图片 / 翻译选中内容」右键菜单
<all_urls> 主机权限 在任意网页注入翻译脚本，并直连你在设置中选择的翻译服务

扩展不会在未经你操作的情况下发起翻译请求。

第三方服务

翻译服务由你自行选择，其数据处理遵循对应服务商的服务条款与隐私政策。使用第三方 AI 服务可能产生费用，由服务商计费。

联系方式

问题与反馈：请在 GitHub Issues 提交。
