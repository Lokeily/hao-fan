隐私政策

最后更新：2026-08-15

「好翻」（Open Translator CN）是一款开源、免费、可自配 API 的浏览器翻译扩展。本政策以清晰、诚实的方式说明：扩展及其运营方如何对待你的数据、与你选定的第三方服务相关的数据流向，以及你所拥有的权利。我们力求措辞准确——不夸大，也不回避。

核心结论：好翻的运营方不在任何服务器上收集、存储或处理你的个人数据。扩展运行在你的浏览器本地；翻译内容只会发往你主动选择的翻译服务商，并由该服务商按其自身条款处理。

一、适用范围

本政策适用于：

  • 好翻浏览器扩展：包括其在你设备上的全部功能（整页翻译、划词翻译、图片翻译、术语表、设置等）；
  • 本官方网站（含文档与下载指引）：本网站为静态页面，不使用 Cookie、不部署统计或广告追踪脚本，也不会向你索取个人信息。

本政策不涵盖你自行选用的第三方翻译服务商，其数据处理由其各自的服务条款与隐私政策约束，请另行查阅。

二、我们收集哪些数据

在服务器层面：我们不收集任何数据。

  • 没有遥测、没有广告追踪、没有用户行为统计；
  • 没有账号体系，不要求注册或登录；
  • 没有自有后端服务器，也没有服务器端日志。

你在使用扩展时产生的所有数据，均只存在于你的设备本地或你选择的翻译服务商处（详见下节）。

三、数据如何处理

翻译内容（网页文本 / 图片）

  • 当你发起翻译时，待翻译的网页文本或图片会直接发送到你在设置中主动选择的翻译服务商（如 DeepSeek、OpenAI、智谱、腾讯混元、Google 翻译等）；
  • 数据经由你配置的 API 端点传输；本项目不参与、不中转、不留存任何翻译内容；
  • 译文与原文仅缓存在你自己的浏览器本地（默认 30 天有效期，可在设置中关闭或清空）。

API 密钥

  • 各服务商的 API Key 仅保存在浏览器本地 storage.local，并按服务商隔离存储；
  • Key 仅随对应的翻译请求发送给该服务商，绝不会被发送给我们或任何第三方；
  • 卸载扩展或清除站点数据后，密钥即被删除。

其他本地数据

  • 暂停翻译的网站列表、你自定义的术语表、翻译统计与偏好设置，均只保存在浏览器本地，不会上传；
  • 图片翻译的临时文件存入浏览器 IndexedDB，读取后即删除，最长 24 小时内自动清理。

本网站

本网站为静态托管，不设置 Cookie、不运行分析脚本、不收集表单信息。你通过 GitHub 与我们交互时，相关数据处理遵循 GitHub 的隐私政策。

四、第三方服务

翻译能力由你自行选择的服务商提供。一旦你选用某家服务商，相应的网页内容、图片与 API Key 将按其指令发往该服务商，并受其服务条款与隐私政策约束。不同服务商的数据处理地点、保留期限与合规资质各不相同，请在使用前自行评估。

其中，「Google 翻译（免 Key）」使用的是非官方公开端点，无服务等级保证，可能随时限流或变更，仅建议用于体验；正式使用请配置支持 API Key 的服务。我们对任何第三方服务商的数据处理行为不承担责任。

五、法律依据（以 GDPR 为例）

对于欧洲经济区（EEA）等地的用户：由于好翻不在服务器端收集或处理个人数据，运营方通常不充当翻译内容的「数据控制者」。数据主要在你的设备本地处理，或在你明确指示下交由你选定的服务商处理。

  • 在本地执行的翻译缓存、设置与术语表处理，属于为向你提供服务所必需（履行合同 / 正当利益）；
  • 将内容发送给你所选定的第三方 AI 服务商，基于你的明确同意，你可随时在设置中更换或停止。

六、数据存储与保留

  • 所有由扩展产生的数据均存储于你的浏览器本地，由你完全掌控；
  • 翻译缓存默认保留 30 天，可在设置中缩短、关闭或手动清空；
  • 卸载扩展、清除浏览器站点数据，或移除对应服务商配置，即可彻底删除相关本地数据。

七、你的权利

根据你所在司法辖区的法律（如 GDPR、CCPA 等），你可能对个人数据享有访问、更正、删除、限制处理、可携带与反对等权利。鉴于我们不在服务器端持有你的任何个人数据，你可直接通过以下方式行使：

  • 本地数据：通过扩展设置清空缓存 / 术语表，或卸载扩展即可删除；
  • 已发送给第三方服务商的数据：请按该服务商的流程向其提出请求；
  • 其他疑问：可通过下方联系方式向我们提出，我们将在不持有数据的前提下尽力协助指引。

八、国际数据传输

好翻自身不会将你的数据传输到任何服务器。但你所选用的第三方翻译服务商可能在你所在国家 / 地区之外处理数据，相关跨境传输受其自身政策与适用法律的约束。请在选用前查阅对应服务商的说明。

九、儿童隐私

好翻并非专门针对儿童设计，我们亦不主动收集任何人的个人信息，包括儿童。若你认为有儿童的数据经由第三方服务商被处理，请通过该服务商或其监护人处理，并可就本扩展行为与我们联系。

十、安全

  • API Key 等敏感信息仅存于浏览器本地隔离存储，不会被我们获取；
  • 翻译请求按你的配置直连所选服务商，并默认携带注入防护；
  • 请妥善保管你的 API Key，避免在其所属平台之外泄露。需提醒的是，没有任何传输或存储方式是绝对安全的，我们仅承诺采取与上述设计一致的合理措施。

十一、本政策的变更

我们可能不时更新本政策以反映功能或合规要求的变化。重大变更将通过项目 Release Notes 或仓库说明予以提示，更新日期见于本页顶部。建议你定期查阅。

十二、免责声明

好翻以开源形式「按原样（as is）」提供，不提供担保。在适用法律允许的最大范围内，运营方不对因使用或无法使用本扩展而产生的任何直接或间接损失承担责任。你应自行评估所选翻译服务商的合规性与适用性，并确保你的使用行为符合所在地法律（例如雇主持有设备、企业网络或受监管行业下的使用要求）。本政策为一般性说明，不构成法律意见。

十三、联系我们

对本政策或数据处理有疑问，可通过 GitHub Issues 与我们联系。由于我们不持有用户数据，通常无法代为查询或删除任何个人数据。

English Summary

Open Translator CN ("好翻") is an open-source browser extension. In short: we do not collect, store, or process any personal data on any server. The extension runs locally in your browser. When you translate, the text or images are sent only to the translation provider you explicitly choose, and are handled under that provider's own terms. Your API keys are stored only in your browser's local storage and are sent solely to the corresponding provider. We operate no backend, no analytics, and no accounts. This static website uses no cookies or tracking. For users in the EEA, the operator is generally not the data controller of translation content; processing occurs on-device or at your chosen provider under your consent. You may exercise your rights by clearing local data or contacting the relevant provider. This policy is provided in Chinese; where local law grants non-waivable rights, those rights are preserved.
