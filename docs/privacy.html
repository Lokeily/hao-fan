隐私政策

本地优先，是我们最重要的设计决策，也是这份政策最短的原因。

最后更新：2026 年 10 月 2 日 ｜ 适配版本：v0.2.16 ｜ 适用产品：好翻浏览器扩展（open-translator-cn）及本官网

一、引言与处理者身份

「好翻」（Haofan，以下简称"本扩展"）是一款依据 MIT 许可证开源的浏览器翻译扩展，由开源社区（以下称"我们"）维护。我们高度重视个人信息保护，按照《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《中华人民共和国数据安全法》等法律法规的要求，制定本政策。

由于本扩展为开源软件且不设中心化运营服务器，我们不作为你的个人信息处理者收集任何个人信息；本政策主要向你说明：扩展在本机处理了哪些数据、哪些数据会在你主动配置并由你授权的情况下发送给你自行选择的第三方服务商，以及你可以如何管理这些数据。

一句话总结：你的网页内容不会被发送给"好翻"——因为根本不存在"好翻服务器"。翻译请求从你的浏览器直连你自己选择的服务商。

二、我们不做什么（负面清单）

  • 不收集浏览记录：你访问了哪些网页、翻译了哪些内容，均不会上报给任何人。
  • 无遥测与埋点：不采集使用行为统计、设备指纹、崩溃报告，不嵌入任何第三方分析脚本。
  • 无广告与追踪器：不包含广告 SDK，不做跨站跟踪。
  • 无账号体系：无需注册登录，不存在云端账户数据。
  • 不出售数据：不存在可供出售的用户数据。

以上声明可通过公开源码验证：仓库中不存在任何遥测上报代码路径。

三、数据的本地存储与处理

3.1 存储在你浏览器中的数据

以下数据仅保存在你本机浏览器的 storage.local 中，不随浏览器同步功能上传（除非你开启浏览器自身的同步），卸载扩展即被删除：

数据用途保存期限与清除方式
API Key（按服务商分别保存）用于向该服务商发起翻译请求时的身份认证直至你删除修改或卸载扩展；设置页可修改

3.2 在内存中临时处理的数据

翻译过程中，待译文本片段会在本机内存中完成遮罩、组装、渲染等处理，处理结果仅写入上述本地存储，处理完成即释放。

四、会离开本机的数据：仅经你主动配置直达所选服务商

当你在设置中填写某服务商的 API Key 并发起翻译时，扩展会将待译文本片段通过 HTTPS 直接发送给你所选择的服务商接口。此过程中：

  • API Key 仅通过 HTTP Authorization 请求头传输，绝不出现在 URL 中；
  • 请求不经过任何"好翻"的中转服务器（不存在这样的服务器）；
  • 服务商对你的文本的处理行为，受该服务商自己的隐私政策与服务条款约束，其为独立的个人信息处理者。

4.1 可选服务商及其隐私政策入口（以你在设置中的选择为准）

DeepSeek、智谱 GLM、腾讯混元、通义千问、Kimi、百度百川、字节豆包、OpenAI、Google Gemini、OpenRouter、DeepL、Microsoft Translator、Ollama（本地运行，数据不出本机）、自定义 OpenAI 兼容端点（由你自己部署和掌控）。各服务商的最新隐私政策请在其官方网站查阅。

特别提示：请仔细阅读你所选服务商的隐私政策后再行配置。若你对某些服务商的数据处理方式不满意，可选择其他服务商或本地模型。

六、关于本官网

本官网（docs 目录静态页面）部署于 GitHub Pages（境外服务器）。访问本官网时，GitHub 会按其自身政策处理必要的网络日志；本官网不嵌入任何统计或追踪脚本。本扩展的使用与是否访问本官网无关。

七、你的权利

依据《个人信息保护法》第四章，你对本机存储的上述数据享有以下权利，且均可即时行使：

  • 查阅与复制：设置页导出备份即为完整副本；翻译历史可在弹窗查看。
  • 更正与补充：所有字段均可直接编辑。
  • 删除：清空缓存 / 清空历史 / 删除 Key 均为即时操作；卸载扩展即删除全部本地数据。
  • 撤回同意：停止使用某服务商（删除其 Key）或卸载扩展，即撤回相应授权。

本扩展不处理不满十四周岁未成年人的个人信息，亦不面向儿童运营。

八、政策的更新

若扩展架构发生影响本政策的变化（例如引入新的数据处理方式），我们会先在源码中以提交形式公示，并在发布说明与本页面中显著标注版本与生效日期后生效。历史版本可在 Git 提交记录中追溯。

九、联系我们与争议解决

你是本扩展的唯一用户与最终控制者。如对本政策有任何疑问、意见或投诉，可通过 GitHub Issues 联系社区；安全漏洞请依照 SECURITY.md 的说明私下披露。若发生个人信息相关争议，你有权依据法律规定向有关主管部门投诉举报。
