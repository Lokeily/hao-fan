首页/适用场景

无论你是谁，都能用上

好翻的使用场景很简单：凡是「要在浏览器里读外文网页」，它都能帮上忙。

读外文资料

论文、技术文档、博客，原文译文对照，查阅效率更高。遇到长文档，可见区域优先让你先读到当前屏幕内容，不必等整页译完。

逛海外社区

论坛、Reddit、GitHub 讨论区，划词即译，边看边懂。动态内容翻译会补译新加载的评论与回复，单页应用切换也不漏。

跨境购物

商品详情、买家评价、帮助文档，母语阅读不再卡壳。可把品牌名、型号写进术语表，保证每次都译得一致。

学外语

保留原文、对照阅读，是练阅读、积累地道表达的好方式。需要更专注时，按网站暂停译文，纯净原文随时回来。

不确定怎么开始？先看 安装方法，或了解全部 功能。

它的边界，我们也说清楚

好翻很擅长「读外文网页」，但也有它不做的事。

适合

在浏览器里读论文、文档、社区、商品页；对照阅读练外语；想自己掌控 API 与数据的人。

暂不适合

完全离线的环境（翻译本身需联网）；对可用性极其敏感、不能接受 Google 免 Key 偶发限流的正式场景。

关于 Google 免 Key

它走非官方免费端点，仅建议用来体验。正式使用请配置支持 API Key 的服务，质量与稳定性更有保障。
