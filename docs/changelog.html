最新版本：v0.1.23 · 2026-08-18

所有版本均开源（MIT）、免费、无遥测。手动加载版不会自动更新，升级请到 Releases 下载新版覆盖加载；商店上架后可通过商店自动更新。

v0.1.23 2026-08-18

  • 语言检测：改为按段落检测语种，已是目标语言即本地跳过（0 Token），杜绝「中译中」；不再依赖全局源语言设置（手动把源语言设成外语时，页面中文 UI 串不再被送进模型）。
  • 标识符遮罩：代码 / 库名 / 品牌专名（useState、react-dom、React、Vue、Linux 等）翻译前替换为占位符、译后还原，不再被翻译成中文；占位符比译文短，顺带节省 completion Token。
  • 首屏批量：首屏从逐条流式（N 个请求）改为单次批量请求，系统提示词 / 术语 / 上下文前缀不再重复发送，显著节省 Token。
  • 翻译模式：新增「自动整页 / 手动点击·划词」开关（设置面板）；手动模式下整页不自动翻译、关闭悬停与动态自动翻译，点击段落或划选文字才翻译，Token 开销最小。
  • 防注入加固：页面来源的上下文（标题 / 前文译文）从 system 移出到 user 消息，页面内容不再以「指令」身份进入系统提示词；system 前缀保持稳定，利于提示词缓存。
  • 其它：批量指令精简（去除与注入防护重复的文案）；识别品牌专名名单；测试契约同步更新。

  • 启用 TypeScript 严格模式，CI 增加测试、类型检查和 Firefox 构建。
